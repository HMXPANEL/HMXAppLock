This document defines:

Goal:

fast

cloud-based Android builds

Important principle:

GitHub Actions should automate development,

---

1. WORKFLOW PHILOSOPHY

Core Goals

GitHub Actions should:

auto-build APKs

validate project stability

speed up testing

reduce manual work

support multi-device testing



---

Important Reality

For THIS app:

real-device testing matters more than complex CI/CD

Because:

overlays

accessibility

OEM behavior

battery optimization


cannot be fully validated in emulators.


---
