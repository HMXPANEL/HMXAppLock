3. LOCKED APPS TABLE

Purpose

Stores:

protected apps

lock rules

relock policies

protection settings



---

Entity

@Entity(
    tableName = "locked_apps",
    indices = [
        Index(value = ["packageName"], unique = true)
    ]
)
data class LockedAppEntity(

    @PrimaryKey(autoGenerate = true)
    val id: Int = 0,

    val packageName: String,

    val appName: String,

    val lockType: String,

    val relockPolicy: String,

    val isEnabled: Boolean,

    val createdAt: Long
)


---

Example Data

packageName	lockType	relockPolicy

com.whatsapp	PIN	instant
org.telegram	fingerprint	screen_off



---

Example Flow

User Locks WhatsApp
↓
Insert Into locked_apps
↓
Foreground Detection Checks Table
↓
Overlay Triggered

4. UNLOCK SESSIONS TABLE

Purpose

---

Entity

@Entity(tableName = "unlock_sessions")

    val packageName: String,

    val unlockedAt: Long,

    val expiresAt: Long
)


---

Example

↓

↓
Expires In 5 Minutes
↓

5. VAULT FILES TABLE

Purpose

Stores encrypted vault metadata.

Important:

actual encrypted files are NOT stored in database

Only metadata is stored.


---

Entity

@Entity(tableName = "vault_files")
data class VaultFileEntity(

    @PrimaryKey(autoGenerate = true)
    val id: Int = 0,

    val encryptedPath: String,

    val originalName: String,

    val fileType: String,

    val thumbnailPath: String?,

    val folderId: Int?,

    val size: Long,

    val createdAt: Long
)


---

Example Flow

↓

↓

↓
Store Metadata In vault_files
